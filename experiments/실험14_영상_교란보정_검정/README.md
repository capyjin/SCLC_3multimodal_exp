# 실험14 — CNN 영상 기여가 '종양'인가 '크롭 기하/전역 밝기'인가

실험10(`exp_trivial_stats.py`)이 남긴 질문에 답한다. PNG 에서 눈감고 뽑은 전역
통계 6개만으로 OS 0.6479 가 나오는데 CNN 은 0.6570 이다(차이 0.009). 크롭 크기가
환자마다 다르므로(382×510, 418×510, 464×511 …) **체격/FOV 자체가 신호일 수 있다.**
실험10 은 "전역 통계도 잘 맞힌다"까지만 보였고, 정작 결정적인 질문 — *그 교란을
통제한 뒤에도 CNN 이 더하는 것이 남는가* — 에는 답하지 않았다.

재학습 없음. 저장된 OOF 위험점수 + 라벨을 보지 않는 이미지 함수만 쓴다(수 초).

```
python experiments/실험14_영상_교란보정_검정/exp_image_confound_adjusted.py
# 기본 OOF = outputs/late_fusion_B_radbert_tests (RadBERT seed42 = 논문 Table 2)
# 산출물   = outputs/image_confound/{results.json,run.log}
```

## 설계의 핵심 — 6개를 성질로 쪼갠 것

| 묶음 | 특징 | 성질 |
|---|---|---|
| `GEOM` | w, h | 크롭 폭·높이. 종양과 무관한 **진짜 교란** 후보 |
| `INT` | mean, std, frac_hot, frac_dark | 전역 밝기·대비·면적. **대사 종양부하의 조악한 측정치** |

이 분해가 결론을 가른다. `INT` 로 보정한 뒤 β_img 가 사라지는 것은 아티팩트의
증거가 아니라 **과잉보정(over-adjustment)** — 종양을 통제해 놓고 종양이 보이냐고
묻는 것 — 이기 때문이다. 분석 [6]이 이 주장을 데이터로 뒷받침한다:
`std`/`frac_hot`/`mean`/`frac_dark` 는 LDH·병기·간전이와 전부 유의하게 붙고
숙주 지표(ECOG·FEV1)와는 안 붙는 반면, `w`/`h` 는 종양 지표 어느 것과도 안 붙고
나이·WBC 하고만 붙는다(체격).

## 결과 (OS)

| 조건 | β_img (pooled) | p |
|---|---|---|
| 보정 없음 `T+I` | +0.327 [+0.103, +0.551] | 0.0042 |
| **기하 보정 `T+GEOM+I`** | **+0.275 [+0.040, +0.509]** | **0.0216 ✅** |
| 강도 보정 `T+INT+I` | +0.156 [−0.126, +0.437] | 0.278 |
| 전부 보정 `T+N+I` | +0.128 [−0.155, +0.412] | 0.376 |

우도비: `T+GEOM vs T+GEOM+I` χ²=5.01, p=0.0252 ✅ / `T+INT vs T+INT+I` χ²=1.16, p=0.282.
기하 단독은 tabular 에 유의한 기여가 없다(`T vs T+GEOM` p=0.0605).

→ **영상 기여는 크롭 기하 아티팩트가 아니다.** 사라지는 것은 종양부하 측정치로
보정했을 때뿐이며, 그것은 "CNN 이 본 것이 대사 종양부하"라는 결론과 같은 말이다.

PFS 는 기하 보정 후 β=+0.132 (p=0.197)로 유의하지 않다 — §10 의 OS/PFS 대비가
RadBERT 기준으로도 유지된다(다만 PFS 는 '0'이 아니라 '경계'로 바뀌었다. §10 갱신 필요).

## 남는 한계 (정직한 기록)

- CNN 위험점수 분산의 **67%** 가 전역 통계 6개로 선형 설명된다(fold 내 R², OS).
  CNN 이 정교한 것을 배운 게 아니라 **전신 대사부하를 재고 있다**는 뜻이다.
  논문 표현은 "novel imaging biomarker" 가 아니라 "MIP 이 담고 있는 대사 종양부하를
  경량 CNN 이 회수한다" 여야 한다.
- `INT` 4종이 종양부하 측정치라는 근거는 **임상 지표와의 상관**이다. 촬영/재구성
  프로토콜이 기관마다 다르면 이 상관이 깨질 수 있으므로 외부 검증에서 재확인 필요.
- 영상 위험점수는 나이(ρ=+0.193)·ECOG(ρ=+0.133)와도 약하게 붙는다. 종양 축만 순수히
  잡은 것은 아니다.
