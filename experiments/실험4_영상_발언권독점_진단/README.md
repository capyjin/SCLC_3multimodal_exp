## ⚠️ 폐기 — 융합 방식 교정 시도

**채택 모델(late fusion 2-way)로 대체됐다. 유지보수하지 않는다.**
**이 두 스크립트와 OGM-GE 보고서는 2026-09-30 에 삭제했다** (논문 미사용). 결론은 아래와
RESULTS.md §9.7 에 남아 있고, 파일은 `archive/before-cleanup-2026-09-30` 태그에 보존돼 있다.

| 스크립트 | 시도한 것 | 결과 |
|---|---|---|
| `exp_balance_dims.py` | 브랜치 차원을 맞춰 영상 몫을 줄이기 (구조 개입) | 실패 — 모델은 영상을 줄일 수단이 생겨도 쓰지 않는다 |
| `exp_fusion_fix.py` | OGM-GE — 브랜치별 gradient 감쇠 (학습 개입) | 실패 — 발언권 46.1% → 46.0%, 사실상 변화 없음 |

전체 리포트(`RESULTS_ogm_ge.md`, 태그에 보존)의 요지는 **실패에서 얻은 두 결론**이다.

1. 구조 개입의 실패가 §9.4 진단을 **확정**했다 — 모델에게 영상을 줄일 권한을
   새로 줘도 쓰지 않으므로, "줄일 수 없어서"가 아니라 **"줄이고 싶지 않아서"** 다
   (구조 문제가 아니라 최적화 문제 = modality competition).
2. gradient 감쇠는 학습 **속도**만 늦추고 **도착지**는 못 바꾼다 — 60 epoch 이면
   천천히라도 같은 곳에 도착한다.

그래서 **late fusion 이 성공한 이유**도 설명된다. 학습 트릭이 아니라 가중치를
정하는 **기준 자체**가 달랐다 — 훈련 데이터가 아니라 out-of-fold 위험점수로
판단하니 영상 계수 0.30 대 tabular 4.44 가 나온다.

이 방향을 계속 판 결과는 실험11(MoE 게이트, 2026-09-30 삭제·태그에 보존)이고, 그쪽도 판정선 Δ0.016 을
넘지 못했다. 세 융합 구조의 같은 조건 비교는 실험12.
