# Stage-aware late fusion — LS/ES가 서로 다른 융합 가중치를 배워야 하는가?

**결론: PFS·OS 모두 "근거 없음(NO_EVIDENCE)".** stage별 융합 가중치를 학습시켜도
현재 모델보다 나아진다는 통계적 근거를 얻지 못했다. 다만 **영상 가중치의 stage 의존성은
방향이 일관되게 관측**되며(OS 5/5 fold, PFS 4/5 fold), 이는 LS 표본(n=72)이 작아
검정력이 부족한 것이지 효과가 0이라는 뜻은 아니다.

---

## 1. 연구 질문과 설계

SCLC는 LS(제한기, n=72)와 ES(확장기, n=166)의 치료법·진행 양상이 다르다. 현재 최고
모델은 C+R 위험도와 영상 위험도를 CoxPH로 결합하는데 **모든 환자에게 같은 가중치**를
쓴다. Stage별로 가중치를 다르게 학습시키면 나아지는가?

### ⚠️ 왜 M1이 기준선인가 (설계상 가장 중요한 지점)

`stage`는 이미 clinical 범주형 13개 중 하나라 **C+R 모델의 입력**이다. 그런데 결합
단계에 stage를 **그냥 변수로 하나 더** 넣기만 해도 성능이 오른다. 즉 두 효과는 다르다:

| 모델 | 공변량 | 역할 |
|---|---|---|
| `M0_shared` | zT, zI | 현재 모델 |
| **`M1_stage_main`** | + sc | **주 비교 기준선** |
| **`M2_stage_aware`** | + sc·zT, sc·zI | **제안 모델** |

**M2 vs M1 = 순수한 stage-aware fusion 효과** (둘 다 stage 직접효과 포함).
M2 vs M0는 참고로만 보고한다 — 개선폭이 커 보여도 "stage별 가중치" 덕인지 "stage 정보
추가" 덕인지 구분되지 않기 때문이다.

가중치 코딩: `sc = +0.5(ES) / −0.5(LS)` 고정 → `weight_LS = β_main − 0.5·β_int`,
`weight_ES = β_main + 0.5·β_int`. ridge로 β_int를 0으로 수축하면 정확히 공통가중치
모델로 수렴한다(= "global weight에 stage별 residual" 구조를 1개 파라미터로 표현).

⚠️ **다만 이 λ는 test 성능을 보고 고른 값이라 그대로 주장하면 낙관 편향이다.**
정식으로 주장하려면 inner-CV로 λ를 고르는 arm이 필요하다(미실행).

## 3. 요청하신 해석 관점 5가지

**① stage 내부 C-index도 개선되는가?**
방향은 개선이지만(PFS LS +0.013/ES +0.006, OS LS +0.022/ES +0.003) **전부 CI가 0을
포함**하고 사전등록 임계값 0.03에 못 미친다. "개선됐다"고 말할 수 없다.

**② 전체만 개선되고 stage 내부는 그대로인가?**
아니다 — 오히려 **반대**다. M2는 stage 내부(LS/ES)에서는 M1보다 낫지만 **전체 fold평균은
더 낮다**(PFS 0.6644 vs 0.6700, OS 0.7093 vs 0.7143). 즉 "전체만 좋아지는 눈속임"은
아니며, 실격 조건에 걸리지 않았다. 대신 stage 내부를 조금 얻고 전체를 조금 잃는 교환이다.

**③ 영상이 특정 stage에서만 도움이 되는가?**
**그렇게 보인다.** OS에서 ES 영상 가중치는 5/5 fold 모두 +0.20 이상인데 LS는 0 근처를
맴돈다. 다만 이 차이가 **성능 개선으로 이어질 만큼 크지는 않다**.

**④ Stage-aware가 더 안정적인가?**
**아니다, 오히려 불안정하다.** fold 표준편차가 커진다(PFS 0.040→0.055, OS 0.051→0.055).
M4_strat_aware는 PFS에서 0.067까지 벌어진다. 파라미터를 2개 더 추정하는 비용이다.

**⑤ 표본 불균형으로 설명되는가?**
**상당 부분 그렇다.** LS 비교쌍은 **520개**뿐인 반면 ES는 **2707개**로 5배 차이다.
LS의 부트스트랩 CI 폭이 ES의 4~7배인 것도 이 때문이다(OS LS CI 폭 0.164 vs ES 0.023).
게다가 fold별 test LS는 20/20/14/11/**7**명으로 극히 불균등해, fold5의 LS 비교쌍은
18개(전체의 3.5%)뿐이다. **본 분석은 쌍 개수로 가중해 이 불균형을 보정했다.**

## 4. 방법론적으로 중요한 발견 3가지

### 4.1 pooled-OOF 지표는 쓰면 안 된다 (초기 분석이 틀렸던 이유)

fold별 모델이 내는 위험점수의 **스케일이 크게 다르다** — 영상 fold별 평균이
0.02 / 0.72 / 0.85 / 1.03 / 1.59로 **80배** 차이난다. 238명 OOF를 전부 이어붙여 순위를
매기면 이 fold 간 drift가 신호로 섞인다.

| Image (PFS) | pooled-OOF (잘못) | fold내·stage내 쌍 (올바름) |
|---|---|---|
| LS | 0.5043 | **0.5846** |
| ES | 0.5791 | **0.5955** |
| 차이 | 0.075 (커 보임) | **0.011 (거의 없음)** |

이 실험의 최초 동기였던 **"영상이 LS에서만 무용하다"는 관찰은 성립하지 않는다.**
융합 모델에서는 인공물이 더 커서 pooled-OOF 0.5779 vs fold평균 0.6531로 **−0.075** 차이났다.

### 4.2 fold별 로그우도를 합산한 LRT는 p값을 심하게 부풀린다

fold별 train set(171명)은 서로 **80% 이상 겹치므로 독립 표본이 아니다.** 로그우도를
5번 더하면 정보량을 ~5배로 착각한다. 실측:

| | PFS M2 vs M1 |
|---|---|
| 합산 LRT (**틀림**) | χ²=22.56, **p<0.0001** |
| fold별 LRT (올바름) | p = 0.21 / 0.90 / 0.013 / 0.055 / 0.091 → **1/5만 유의** |

### 4.3 M2p(주효과 없는 설계)는 교란된다

`zT, zI, sc·zT, sc·zI`(주효과 sc 없음)는 상호작용 항이 **stage 주효과를 숨겨서 담는다**
(영상 위험도의 train 평균이 0이 아니므로 `sc·zI = c·sc + sc·(zI−c)`). 실제로 M2p는
LS에서 가장 높지만(OS 0.6900) 전체는 낮다 — 해석 불가능한 값이므로 보고에서 제외해야 한다.

## 6. 한계

1. **검정력 부족이 근본 원인.** LS는 fold당 train 이벤트 37~50개뿐이다. 상호작용
   검출은 통상 주효과의 4배 표본이 필요하다. 이 결과는 "효과가 0"이 아니라
   **"n=72로는 판정할 수 없다"** 로 읽어야 한다.
2. **음성 대조군 미실행.** 무작위 라벨 200회(NC1), 다른 임상 이분변수(NC2, 예: `dm`)
   대조를 돌리지 않았다. 현 결과가 NO_EVIDENCE라 우선순위가 낮았지만, 향후 유의한
   결과가 나오면 반드시 필요하다. `--nc1_draws 200` 으로 실행 가능.
3. **λ를 inner-CV로 고르는 arm 미실행.** §2.4의 λ 곡선은 test를 보고 고른 값이라
   그대로 주장할 수 없다.
4. **fold가 stage 균형이 아니다.** test LS가 20/20/14/11/7명으로 불균등하다. 다만
   `splits/trimodal_common_5fold_seed42_v1.csv`는 기존 모든 결과와 공유하는 고정
   분할이라 바꾸지 않았다(바꾸면 비교 가능성이 사라진다). 쌍 가중으로 보정했다.
5. **3-way(clinical·판독지·영상 각각) stage-aware arm 미실행.** 별도 실험에서
   3-way가 2-way보다 낮음이 이미 확인돼(PFS 0.6313 vs 0.6621) 우선순위에서 제외했다.
